# Sports Research OS — Prototype

Standalone prototype built from the Alex Baseball concept.

Core rule:
Never just give a prediction. Show the evidence, explain the reasoning, and update the view as the game changes.

Prototype features:
- Sport selector: Baseball, Football, Basketball, Soccer
- Mode selector: Research, Prediction, Live Game, Deep Dive
- Sport-specific evidence cards and signal boards
- Prediction explanation with counter-evidence and uncertainty
- Live "What Changed?" concept
- Natural-language question box
- Mobile-first static site, suitable for GitHub Pages, Vercel, Netlify, or any static host

Truth boundary:
- Baseball is the first candidate for a live data adapter.
- The other sports use clearly labeled prototype/demo data until live connectors are added.
- The prototype is informational and does not guarantee outcomes.
